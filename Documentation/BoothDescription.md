# Moruton Gimmicks Package

Moruton Laboratory のアバター向けギミック・ツール集です。
主に VRChat アバター向けの便利なコンポーネントが含まれています。

## 主な特徴

- **Modular Avatar 自動対応**:
  - `Modular Avatar` が導入されている環境では自動的に `AvatarTagComponent` を継承します。
  - 非導入環境でも通常の `MonoBehaviour` として動作するため、環境を選びません。
- **もルラボのギミックの導入補助ツール**:
  - 煩雑なアバターへのオブジェクト配置や設定を、専用のコンポーネントで直感的に行えます。
- **インストール補助機能**:
  - ギミックの導入に必要なオブジェクトの配置や設定を補助します。
- **エディタ内自動更新**:
  - 新しいバージョンがリリースされるとInspector内で通知
  - ワンクリックでパッケージを更新可能

## 収録内容

- **ギミック導入時におけるアイテムの位置変更を簡単にするツール**:
  アイテムの微調整や配置を効率化します。
- **ギミック導入時におけるアイテムの入れ替えを簡単にするツール**:
  複数のアイテムをワンクリックで入れ替えられます。
- **ギミック導入時における複雑なセットアップを簡単にするツール**:
  煩雑なコンポーネント設定や関連付けを簡略化します。

## インストール方法

本パッケージは [VRChat Package Manager (VCC)](https://vcc.docs.vrchat.com/) 経由での導入を推奨しています。

1. [公式配布ページ](https://moruton1119.github.io/com.moruton.gimmicks/)にアクセス。
2. 「Add to VCC」ボタンをクリックしてリポジトリを追加してください。
3. VCCのプロジェクト管理画面から `Moruton Gimmicks Package` をインストールしてください。

## 使い方

本パッケージは、対応するもルラボ製ギミックを導入・使用する際に必要となる共通基底パッケージです。
対応ギミックをご購入・導入される際に、併せてインストールしてご使用ください。
詳細な使用方法は、各ギミックの導入マニュアルをご確認ください。

## 更新方法

新しいバージョンがリリースされると、Inspectorのヘッダー部分に通知が表示されます。
以下のいずれかの方法で更新できます:

- **自動更新**: 「自動更新」ボタンでエディタ内から直接更新
- **VCCで更新**: 「VCCで更新」ボタンでVCCを開き更新
- **手動ダウンロード**: GitHubリリースページからダウンロード
